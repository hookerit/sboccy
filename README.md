# Sboccy

Un'app Android per bere più acqua: ogni giorno una pianta diversa sboccia a ogni bicchiere.

Sboccy si scarica da Google Play. Il suo sito è **https://hookerit.github.io/sboccy/**
(GitHub Pages, dalla cartella `docs/` del ramo `main`):
- `docs/index.html` — la pagina dell'app;
- `docs/privacy.html` — l'informativa sulla privacy di Sboccy (l'indirizzo da dare alla Play Console);
- `sboccy/privacy.md` — la stessa informativa, al vecchio indirizzo (usato dalle versioni di prova già installate): tienila uguale a `docs/privacy.html`;
